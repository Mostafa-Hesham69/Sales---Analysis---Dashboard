>> Sales Analysis Dashboard | Microsoft Excel

>> Project Overview
This project focuses on analyzing sales data and building an interactive dashboard using Microsoft Excel to turn raw data into meaningful business insights.

>> Tools & Technologies
- Microsoft Excel: Data analysis and dashboard development.
- Power Query: Data cleaning and transformation.
- Power Pivot: Data modeling.
- Pivot Tables: Data summarization and performance analysis.
- DAX: Creating analytical measures and calculations.

>> Project Objectives
- Analyze sales performance across different brands, branches, and product categories.
- Monitor key performance indicators (KPIs).
- Explore sales trends and compare performance across business dimensions.
- Support data-driven decision-making through interactive visualizations.

>> Dashboard Features
- Total Sales.
- Total Orders.
- Average Order Value.
- Interactive filters (Slicers).
- Sales analysis by brands, branches, and product categories.

>> Project Files
- Excel Project: The main workbook containing the analysis and interactive dashboard.
- Dashboard PDF: A static version of the dashboard, if included in the repository.
- Project Documentation PDF: An explanation of the project.
- Dashboard Image: A preview of the dashboard.

>> Additional Analysis
A supporting Pivot Table was used to analyze the top 5 products. This analysis is available in the Excel workbook but is not displayed on the dashboard.
